# CRM Система для учёта заявок

Упрощенное и удобное веб-приложение по типу CRM-систем для управления заявками клиентов с функциями планирования задач и контроля просрочек. Работает как локальный сервер с открытием в браузере, легко публикуется в один `.exe` файл.

## Основной функционал

- **Список всех заявок** – таблица с ID, именем, телефоном и адресом клиента.
- **Создание новой заявки** – модальное окно с полями: имя, телефон, локация, описание, дата выполнения.
- **Просмотр и редактирование** – клик по записи открывает карточку с возможностью изменить или удалить заявку.
- **Раздел "Задачи"** – автоматическая группировка по датам:
  - Сегодня
  - Завтра
  - Неделя (от послезавтра до +7 дней)
  - Просроченное (отображается отдельным блоком сверху, если есть)
- **Интерактивный интерфейс** – выполнено в тёмной стилистике с полупрозрачными элементами, адаптивно для ПК.
- **Локальная база данных SQLite** – не требует установки сервера, все данные хранятся в файле `deals.db`.
- **Автоматическое применение миграций** – при первом запуске база создаётся автоматически.

## Технологии

- **Backend**: ASP.NET Core 8.0, Entity Framework Core (SQLite)
- **Frontend**: чистый HTML, CSS (с `backdrop-filter`), Vanilla JavaScript (Fetch API)
- **БД**: SQLite (файл `Data/deals.db`)
- **Публикация**: self-contained single-file `.exe` для Windows (x64)

## Сборка и публикация

Чтобы создать самодостаточный `.exe` для Windows:

```bash
dotnet publish -c Release -r win-x64 /p:PublishSingleFile=true --self-contained true
```

Готовый файл появится в папке `bin\Release\net8.0\win-x64\publish\`. Скопируйте всё содержимое этой папки на целевой компьютер.
